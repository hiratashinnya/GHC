# testcase: tool_input_spy.py

対象スクリプト: `.github/hooks/scripts/entrypoints/tool_input_spy.py`

---

## テストケース一覧

| テストID | 観点 | 入力 | 期待動作 |
|----------|------|------|----------|
| SP-001 | `_sanitize` 短文字列（トランケートなし） | 100 文字の文字列 | 変更されずそのまま返す |
| SP-002 | `_sanitize` 長文字列（トランケート） | 400 文字の文字列 | 先頭 300 文字 + `...[truncated 100 chars]` の文字列を返す |
| SP-003 | `_sanitize` dict（ネスト処理） | `{"key": 400文字}` | value がトランケートされた dict を返す |
| SP-004 | `_sanitize` list（要素処理） | `[400文字, 100文字]` | 長い要素のみトランケートされたリストを返す |
| SP-005 | `main` デバッグ有効時 | デバッグフラグ有り + stdin にペイロード | ログファイルに `"spy"` ラベルのエントリが書き込まれる |
| SP-006 | `main` デバッグ無効時 | デバッグフラグなし + stdin にペイロード | ログファイルへの書き込みが発生しない |
| SP-007 | `_sanitize` 非文字列 dict 値（int） | `{"count": 42}` | `{"count": 42}` をそのまま返す（変換なし） |
